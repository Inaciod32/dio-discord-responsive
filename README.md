# Discord — Desafio de Responsividade DIO

Projeto desenvolvido para o desafio **Construindo um Layout Responsivo para o Site do Discord com CSS**, da formação de CSS da DIO.

## Objetivo

Reproduzir uma landing page inspirada no Discord, colocando em prática principalmente conceitos de responsividade no CSS.

## Tecnologias utilizadas

- HTML5
- CSS3

## Conceitos praticados

- Design responsivo e adaptação entre diferentes tamanhos de tela
- Media Queries
- Flexbox
- Unidades responsivas
- `clamp()`
- Imagens fluidas
- Tipografia responsiva
- Organização semântica do HTML

## Responsividade

O layout possui adaptações para:

- Desktop
- Tablet
- Smartphone

Em telas menores, as seções passam de duas colunas para uma coluna, os botões ocupam a largura disponível e o conteúdo do hero muda o alinhamento para facilitar a leitura.
